# Hand Gesture-Based Screen Brightness Control
This Python project utilizes a webcam feed to control the screen brightness based on hand gestures. By detecting the distance between the thumb and index finger using Mediapipe's hand tracking solution, the brightness of the screen is dynamically adjusted in real-time.

## Features
<br/> Hand Tracking: Leverages Mediapipe to detect hands and landmarks accurately.
<br/> Gesture-Based Brightness Control: Adjust screen brightness by changing the distance between your thumb and index finger.
<br/> Real-Time Processing: Processes the webcam feed and applies changes instantaneously.
<br/> Interactive Visualization: Displays hand landmarks on the video feed for better understanding and interaction.

## Requirements
<br/> Python 3.x
<br/> OpenCV
<br/> Mediapipe
<br/> Screen Brightness Control (screen-brightness-control)
<br/> NumPy
